Bounce Bhai – Privacy Policy

Last updated: 28 October 2026

Bounce Bhai is a private automation tool used only by the owner of the YouTube channel @bouncebhaiofficial to publish its own Shorts, update its channel details, read channel statistics and reply to comments on its own videos.

Data we access

Through the YouTube Data API (scope youtube.force-ssl) the app accesses only the authorizing channel's videos, comments, channel details and statistics. It does not access Gmail, contacts, Drive or any other Google data.

How data is used and stored

Data is used only to operate the channel's own uploads and replies. The OAuth refresh token is stored encrypted in the project's repository and is never shared. No personal data is sold, shared with third parties, or used for advertising.

Google API Services

Bounce Bhai's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
